# HeroUI Chat

I helped build HeroUI Chat from prototype to production while working as a Software Engineer at HeroUI, from November 2024 to June 2025. This was part of my full-time work at the company.

[View the Product Hunt launch](https://www.producthunt.com/products/heroui-chat?launch=heroui-chat)

## From an idea to an interface

HeroUI Chat lets people describe an interface or provide a screenshot, then work with the generated result. It uses the HeroUI component library and brings the design preview and editable code into the same workspace.

For example, someone can describe a booking page, inspect the generated interface, and continue refining it. Developers can also edit the code directly through Dev Mode. The product is built around that continued editing process, rather than stopping after the first generation.

## My contribution

I was one of the builders of the initial product, helping turn the prototype into a working application. My work covered the generation and editing experience, previews, and the product features needed to move from an idea to a usable interface.

The [public launch](https://www.producthunt.com/products/heroui-chat?launch=heroui-chat) shows the product and its original positioning. It is the best place to see the released experience without going into internal company details.
