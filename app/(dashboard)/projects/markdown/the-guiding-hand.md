# The Guiding Hand

The Guiding Hand was a student team project for Gebirah, presented by Team Echolestia. We built connected client and admin applications to make communication with counsellors and access to support information easier.

## Two sides of the same conversation

The client application brought together articles, counsellor messaging and an AI chatbot. The admin application supported conversations, article management and summaries that could help staff review a case.

For example, a client could read information and contact a counsellor. The staff-facing application gave the counsellor a corresponding place to respond and review the conversation.

## Design and testing

The team worked through personas, storyboards and prototypes before implementing the applications. We used user stories to describe the flows and Cucumber with Puppeteer to test them.

The linked presentation includes the design process, application screens and demonstration. This was a student prototype; the page does not claim a clinical evaluation or production deployment.
